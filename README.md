🎬 Pixar Website Clone

A responsive front-end recreation of the Pixar homepage, built as a personal practice project to explore modern layout, styling, and image-heavy page design

🔗 **Live Demo:** [https://09rehanali.github.io/Pixar/](https://09rehanali.github.io/Pixar/)

---

## ✨ Features

- Responsive layout that adapts to desktop, tablet, and mobile screens
- Navigation bar with **Films**, **Technology**, **Careers**, and **More** sections
- Hero banner with background and featured artwork
- Featured films / "Now Streaming" showcase sections
- Careers at Pixar section
- Multi-column footer with links for Films, Tech, Careers, and More
- Optimized images in `.webp` format for faster loading

## 🧭 Page Sections

| Section            | Description                                                |
| ------------------ | ---------------------------------------------------------- |
| **Header / Nav**   | Logo and main navigation menu                              |
| **Hero**           | Large banner with featured artwork                         |
| **Featured Films** | Grid of film and short artwork                             |
| **Careers**        | Intro to working at Pixar                                  |
| **Now Streaming**  | Highlights for titles available on Disney+                 |
| **Footer**         | Quick links: Films, Tech, Careers, More, and privacy links |

## 🚀 Getting Started

### Run locally

```bash
# Clone the repository
git clone https://github.com/09rehanali/Pixar.git

# Move into the project folder
cd Pixar

# Open index.html in your browser
```

You can also use a local server such as the VS Code **Live Server** extension for auto-reload while editing.

### Deploy

The site is hosted on **GitHub Pages**. To deploy your own copy:

1. Fork this repository
2. Go to **Settings → Pages**
3. Select the `main` branch as the source
4. Save, and your site will be live in a minute or two
